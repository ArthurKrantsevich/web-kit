One interface for every tool. New package `@web-kit/ui`: Select, Segmented, Tooltip, Button, CopyButton, the editor layout, file open and download. All four utilities use it: the same select, tooltips on every button, segments and Copy that never change width, and a common set of actions (Open file, Paste, Sample, Clear, Copy, Download). JSON Convert moves to the editor layout.
