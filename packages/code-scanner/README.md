# @web-kit/code-scanner

Read QR codes from an image: file, drop or paste, decoded on your device.

> Not published to npm yet.

```ts
import { codeScanner } from "@web-kit/code-scanner/core";
```

```tsx
import { CodeScanner } from "@web-kit/code-scanner";
import "@web-kit/code-scanner/styles.css";
```
