# @web-kit/text-compare

Compare two texts or files side by side, by line, word or character, and export a patch.

> Not published to npm yet.

```ts
import { textCompare } from "@web-kit/text-compare/core";
```

```tsx
import { TextCompare } from "@web-kit/text-compare";
import "@web-kit/text-compare/styles.css";
```
