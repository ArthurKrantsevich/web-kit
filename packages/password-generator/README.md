# @web-kit/password-generator

Passwords, passphrases, PINs and pronounceable passwords from a secure random source, with their exact entropy.

> Not published to npm yet.

```ts
import { passwordGenerator } from "@web-kit/password-generator/core";
```

```tsx
import { PasswordGenerator } from "@web-kit/password-generator";
import "@web-kit/password-generator/styles.css";
```
