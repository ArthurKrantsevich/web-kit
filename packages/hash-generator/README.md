# @web-kit/hash-generator

MD5, SHA-1, SHA-2, SHA-3, BLAKE2, BLAKE3, RIPEMD-160 and CRC32 of a text or a file, with a checksum check and HMAC.

> Not published to npm yet.

```ts
import { hashGenerator } from "@web-kit/hash-generator/core";
```

```tsx
import { HashGenerator } from "@web-kit/hash-generator";
import "@web-kit/hash-generator/styles.css";
```
