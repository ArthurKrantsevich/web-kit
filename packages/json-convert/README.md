# @web-kit/json-convert

Convert JSON to YAML, CSV, XML and TypeScript, and CSV to JSON. Every result is checked.

> Not published to npm yet.

```ts
import { jsonConvert } from "@web-kit/json-convert/core";
```

```tsx
import { JsonConvert } from "@web-kit/json-convert";
import "@web-kit/json-convert/styles.css";
```
