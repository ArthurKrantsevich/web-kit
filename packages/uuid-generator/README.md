# @web-kit/uuid-generator

UUID v1, v3, v4, v5, v6 and v7, ULID and NanoID in bulk, and any of them taken apart.

> Not published to npm yet.

```ts
import { uuidGenerator } from "@web-kit/uuid-generator/core";
```

```tsx
import { UuidGenerator } from "@web-kit/uuid-generator";
import "@web-kit/uuid-generator/styles.css";
```
